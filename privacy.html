Privacy Policy

Effective: April 2026 · Updated for advertising transparency · Client-side detection
Last updated: August 13, 2026

WhatPhone ("we", "our", or "the Service") is committed to protecting your privacy and providing transparent information about data practices. This Privacy Policy explains how WhatPhone handles information, including our client-side device detection and any third-party advertising services such as Google AdSense.

Key Principle: WhatPhone's core device detection runs entirely in your browser and does not transmit personal device data to our servers. However, if advertisements are displayed (including via Google AdSense), third-party vendors may use cookies and similar technologies as described below.

1. Information We Do Not Collect Directly

WhatPhone is primarily a client-side web application. When you use the device detection features:

  • No personal information (name, email, phone number) is requested or collected by WhatPhone.
  • No device identifiers or detection results from the "Detect My Phone" feature are sent to any WhatPhone server.
  • No first-party analytics scripts or tracking libraries controlled by WhatPhone are embedded for user profiling.

All core detection — User Agent parsing, screen resolution, battery status, network information, hardware capabilities, and feature detection — is performed using JavaScript APIs inside your browser. Results are displayed on your screen and are not transmitted by WhatPhone.

2. How Detection Works (Client-Side)

When you click "Detect My Phone", your browser executes JavaScript that reads publicly available browser APIs, including:

  • Navigator API — browser name, OS, language, user agent string.
  • Screen API — resolution, color depth, orientation.
  • Battery Status API — battery level and charging status (if supported).
  • Network Information API — connection type, downlink, RTT (if supported).
  • Hardware concurrency & Device Memory API — CPU cores and approximate RAM.
  • Feature detection — WebGL, WebGPU, Bluetooth, NFC, and other browser capabilities.

This information stays on your device for the detection feature. WhatPhone does not log or store these detection results.
