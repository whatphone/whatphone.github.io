How to use the ppi calculator

  1. Enter the resolution. Type the screen's pixel width and height, for example 1080 and 2400. Use the Use this device's screen button to estimate it.
  2. Add the diagonal size. Enter the diagonal in inches, measured corner to corner across the visible screen. Spec sheets list it, such as 6.1 or 27.
  3. Read the PPI. The big number is pixels per inch. Higher means sharper. The classification tells you how it compares.
  4. Use the extras. Dot pitch, true physical size and the viewing distance help you compare screens or pick a monitor.

What is PPI?

PPI stands for pixels per inch. It counts how many pixels fit along one inch of a display, so a higher number means finer detail and smoother text. It depends on two things: the resolution of the screen and its physical size. Two screens with the same resolution can have very different PPI if one is much larger.

PPI vs. DPI

PPI describes screens. DPI, dots per inch, describes printers. People often use them interchangeably for monitors, but PPI is the correct term for a display.

What is dot pitch?

Dot pitch is the distance between neighboring pixel centers, in millimeters. It is the inverse view of the same idea: lower dot pitch means more densely packed pixels.

How the retina distance works

A person with normal vision can resolve detail down to about one arc-minute. Dividing 3438 by the PPI gives the distance in inches beyond which individual pixels become indistinguishable. A phone at 460 PPI blends together beyond about 7.5 inches, while a 27-inch 1440p monitor at 109 PPI needs roughly 31 inches.

Want to check a real device? The online ruler helps you measure the physical screen size, and the dead pixel test checks the panel itself.
