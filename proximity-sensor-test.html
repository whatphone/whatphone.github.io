FAQ

Proximity Sensor Test — Common Questions

Everything you need to know about testing your phone's proximity sensor.

Open this page on your phone, tap "Start Proximity Test", and allow sensor access when prompted. Then simply cover the top of your phone (near the earpiece or front camera) with your hand. The screen should change to indicate the sensor has detected an object. When you remove your hand, the sensor should return to the "far" state.

During a call, the proximity sensor detects when the phone is held against your ear. When it senses an object (your head), it turns off the touchscreen and dims the display to prevent accidental taps and save battery. When you move the phone away, the screen turns back on.

A non-working proximity sensor can be caused by a dirty screen protector covering the sensor, a hardware failure, or a software glitch. Try cleaning the top of the screen, removing any screen protector or case that covers the sensor, restarting your phone, and running this test again. If the sensor still doesn't respond, it may need a repair.

The Proximity Sensor API is currently supported on Chrome for Android and other Chromium-based mobile browsers. Safari on iOS does not expose the proximity sensor to web apps, so the test will show as "unsupported" on iPhones. Desktop browsers also do not have a proximity sensor.
